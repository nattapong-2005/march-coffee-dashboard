สร้างโปรเจกต์เว็บ Dashboard สำหรับระบบร้านกาแฟชื่อ **March Coffee** โดยใช้ Next.js และออกแบบให้มีความเป็น Premium Minimal Modern Coffee Shop

โปรเจกต์นี้เป็นระบบ Dashboard สำหรับ “แสดงข้อมูลเท่านั้น” ในระยะแรก ยังไม่ต้องมีระบบ CRUD จริง, Backend จริง หรือ Database จริง ให้ใช้ Mock Data ที่สมจริงทั้งหมด และจัดโครงสร้างโค้ดให้พร้อมต่อ API / Database ภายหลังได้ง่าย

## Tech Stack

ใช้เทคโนโลยีดังนี้

* Next.js รุ่นล่าสุด
* App Router
* TypeScript
* Tailwind CSS
* shadcn/ui
* Recharts
* Lucide Icons

หลีกเลี่ยง dependency ที่ไม่จำเป็น

เขียน Component ให้ reusable และแยกโครงสร้างไฟล์อย่างเป็นระบบ

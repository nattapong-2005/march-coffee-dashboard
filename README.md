# March Coffee Dashboard

A modern, minimalist coffee shop management dashboard application built with Next.js App Router, TypeScript, and Tailwind CSS.

## Features

- **Sales Analytics:** Real-time revenue, order tracking, and sales performance charts.
- **Inventory Management:** Stock tracking, low-stock alerts, and item management.
- **Customer Insights:** Order history, customer metrics, and loyalty tracking.
- **Responsive Interface:** Clean, high-contrast dark/light UI optimized for desktop and mobile.

## Tech Stack

- **Framework:** Next.js 16 (App Router)
- **UI & Components:** React 19, Lucide Icons, Recharts
- **Language:** TypeScript
- **Styling:** Tailwind CSS v4, PostCSS

## Getting Started

### Prerequisites

- Node.js 18.17+ or higher
- npm, yarn, pnpm, or bun

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/nattapong-2005/march-coffee-dashboard.git
   cd march-coffee-dashboard
   ```

2. Install project dependencies:
   ```bash
   npm install
   ```

3. Start the development server:
   ```bash
   npm run dev
   ```

4. Open [http://localhost:3000](http://localhost:3000) in your browser.

## Available Scripts

- `npm run dev` — Run the local development server.
- `npm run build` — Create an optimized production build.
- `npm run start` — Run the production build server.
- `npm run lint` — Run ESLint checks across project files.
